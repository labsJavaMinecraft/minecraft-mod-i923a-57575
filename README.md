# minecraft-mod-i923a-57575
Инструментальные средства разработки ПО Состав команды: Епифанов Арен, Самерханов Марсель, группа И9-23А
Сруктура проекта: src/main/java - классы мода, src/main/resources - ресурсы мода
Главный класс - src/main/java/magnet/Magnet.java
magnet:magnet - Инструмент магнит, позволяющий притягивать предметы

Свойства объекта:

Максимальное количество: 1 предмет в одном слоте инвентаря. Это ограничение позволяет сделать магнит уникальным инструментом.
Назначение: магнит предназначен для использования в качестве инструмента для притягивания предметов.
Тип объекта: предмет, который хранится в инвентаре и не размещается как блок.

Рецепт создания магнита:

Для создания магнита нужны один железный слиток, один золотой слиток и одна единица редстоуна.
Железо и золото используются как основные материалы, а редстоун символизирует магнитные свойства предмета. 
Рецепт требует три ингредиента, поэтому получение магнита не слишком простое. 
При этом магнит нельзя складывать с другими магнитами в одном слоте, поскольку его максимальное количество составляет один предмет.

Дополнительное поведение объекта

**Действие:** использование магнита правой кнопкой мыши.

**Ожидаемый эффект:** при использовании магнита игрок получает сообщение «Магнит активирован!».

Сценарий проверки:

1. **Исходное состояние:** магнит находится в руке игрока.
2. **Действие игрока:** игрок нажимает правую кнопку мыши.
3. **Ожидаемый результат:** появляется сообщение «Магнит активирован!».

Условие срабатывания:

Сообщение появляется только при использовании зарегистрированного предмета `magnet:magnet`. При использовании других предметов сообщение не появляется.

Способ проверки:

Проверка выполняется по сообщению в чате игры. Дополнительно нужно использовать обычный предмет и убедиться, что сообщение не появляется.

Magnet — мод для Minecraft

1. Описание проекта

Magnet — модификация для Minecraft, созданная с использованием Fabric. Основная цель проекта — добавить в игру новый предмет «Магнит», который можно получить и использовать во время игры.
При использовании магнита игрок получает сообщение «Магнит активирован!». Проект разработан в рамках учебной работы по созданию модификаций Minecraft.

2. Совместимость

Для работы мода необходима следующая конфигурация:
Minecraft: 1.21.11
Fabric Loader: 0.18.6 или совместимая более новая версия
Java: 21 или совместимая версия, удовлетворяющая требованиям проекта
Fabric API: версия, совместимая с используемой версией Minecraft и Fabric Loader
Перед установкой необходимо убедиться, что игровая среда соответствует указанным требованиям. Работа на других версиях Minecraft не гарантируется без дополнительной проверки.

3. Установка

Установить Minecraft версии 1.21.11.
Установить Fabric Loader для соответствующей версии игры.
Установить совместимую версию Fabric API.
Собрать проект или получить готовый JAR-файл мода.
Поместить JAR-файл в каталог mods используемого игрового профиля.
Запустить игру через профиль Fabric.
Проверить наличие предмета и его работоспособность.
Если мод не загружается, необходимо проверить версии игры, загрузчика, Fabric API и содержимое журнала запуска.

4. Предмет и его свойства

Название предмета: Магнит.
Идентификатор предмета: magnet:magnet.
Основные свойства:
предмет нельзя складывать в стопку, поскольку для него установлено ограничение maxCount(1);
предмет имеет собственную текстуру и русское название;
предмет зарегистрирован в исходном коде мода;
предмет предназначен для использования в игровом мире.

5. Получение и использование

Предмет можно получить предусмотренным в проекте способом: через рецепт крафта, если рецепт присутствует в итоговой сборке, либо командой:
/give @p magnet:magnet
Для проверки поведения необходимо взять магнит в руку и использовать его. При корректной работе появляется сообщение:
«Магнит активирован!»
При проверке рецепта необходимо убедиться, что он действительно распознаётся установленной игрой.

6. Сборка проекта

Для сборки используется Gradle Wrapper, находящийся в корневой папке проекта.
В Windows Terminal необходимо выполнить: .\gradlew.bat clean build
После успешной сборки итоговый JAR следует найти в папке build/libs. Для установки нужно выбрать основной файл мода, а не вспомогательный файл с суффиксом -dev или -sources, если такие файлы создаются.
Имя итогового JAR: указать после выполнения сборки.

7. Известные ограничения

Работа мода на версиях Minecraft, отличных от указанной, не подтверждена.
Для запуска требуется совместимая версия Fabric API.
Магнит выводит сообщение при использовании, но не реализует автоматическое притягивание предметов, если такая функция отдельно не добавлена в код.
Совместимость итогового JAR необходимо подтвердить запуском установленной модификации.
