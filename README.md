Главный класс - src/main/java/magnet/Magnet.java
magnet:magnet - Инструмент магнит, позволяющий притягивать предметы

Свойства объекта:

Максимальное количество: 1 предмет в одном слоте инвентаря. Это ограничение позволяет сделать магнит уникальным инструментом.
Назначение: магнит предназначен для использования в качестве инструмента для притягивания предметов.
Тип объекта: предмет, который хранится в инвентаре и не размещается как блок.

Рецепт создания магнита:

Для создания магнита нужны один железный слиток, один золотой слиток и одна единица редстоуна.
Железо и золото используются как основные материалы, а редстоун символизирует магнитные свойства предмета. 
Рецепт требует три ингредиента, поэтому получение магнита не слишком простое. 
При этом магнит нельзя складывать с другими магнитами в одном слоте, поскольку его максимальное количество составляет один предмет.

Дополнительное поведение объекта

**Действие:** использование магнита правой кнопкой мыши.

**Ожидаемый эффект:** при использовании магнита игрок получает сообщение «Магнит активирован!».

Сценарий проверки:

1. **Исходное состояние:** магнит находится в руке игрока.
2. **Действие игрока:** игрок нажимает правую кнопку мыши.
3. **Ожидаемый результат:** появляется сообщение «Магнит активирован!».

Условие срабатывания:

Сообщение появляется только при использовании зарегистрированного предмета `magnet:magnet`. При использовании других предметов сообщение не появляется.

Способ проверки:

Проверка выполняется по сообщению в чате игры. Дополнительно нужно использовать обычный предмет и убедиться, что сообщение не появляется.
